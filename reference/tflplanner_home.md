# Where tflplanner keeps its settings and the studies' saved state

Where tflplanner keeps its settings and the studies' saved state

## Usage

``` r
tflplanner_home()
```

## Value

The home folder (it may not exist yet: see
[`setup_tflplanner()`](https://ichirio.github.io/tflplanner/reference/setup_tflplanner.md)).
