# tflplanner's settings

tflplanner's settings

## Usage

``` r
tflplanner_config(home = tflplanner_home())

studies_root(home = tflplanner_home())
```

## Arguments

- home:

  The home folder.

## Value

A list: `studies_root`, `last_study`, `language`, and when set `port`,
`update_channel`, `check_updates`.
