# Presets for cells and column headers

Ready-made rows to start from and adjust: the cell templates and the
column headers of the company standards
([`company_standards()`](https://ichirio.github.io/tflplanner/reference/standards_template.md)).

## Usage

``` r
cell_presets()

header_presets()
```

## Value

`cell_presets()` and `header_presets()` return a named list of data
frames in the columns of their sheet.
